1. VISIÓN GENERAL
================================================================================

Se construyó un ecosistema completo de "segundo cerebro" que conecta:
- Bóveda de Obsidian (notas, bitácora, conocimiento)
- GitHub (SSH, repositorios, issues)
- Cloudflare (Pages, D1, Functions)
- App unificada (webapp + PWA)
- Integraciones futuras (voz, IA, Coucou, Hermes)

El objetivo final es una sola app (web + móvil) que unifique todo.

================================================================================

   - Ubicación: Proyecto predeterminado/github-access-console/
   - Local: http://127.0.0.1:8787
   - Cloudflare: https://github-access-console.pages.dev
   - Funciones: estado SSH, huella, handshake, registro en vivo, pasos visuales
   - Tema: morado (violeta #8b5cf6, lavanda #a78bfa)
   - Archivos: server.py, public/index.html, styles.css, app.js, build_static.py, deploy.sh
   - Base de datos: no (solo estado local)

B. SEGUNDO CEREBRO (Quartz v5)
   - Ubicación: Proyecto predeterminado/quartz/
   - URL: https://segundo-cerebro-e4v.pages.dev
   - Funciones: grafo interactivo, búsqueda, backlinks, modo oscuro, callouts, wikilinks
   - Tema: morado (personalizado en quartz/styles/custom.scss)
   - Contenido: symlink a la bóveda (58 notas)
   - Config: quartz.config.yaml (español, baseUrl, ignorePatterns)

C. AUTH PORTAL (Login/Register/Logout + D1)
   - Ubicación: Proyecto predeterminado/auth-portal/
   - URL: https://auth-portal-px1.pages.dev
   - Funciones: registro, login, logout, perfil, personalización
   - Base de datos: Cloudflare D1 (SQLite en el edge)
   - Tabla users: id, name, email, password (SHA-256), avatar, accent, display_name, created_at, last_login
   - API: /api/register, /api/login, /api/me, /api/preferences
   - Avatares: DiceBear (8 estilos: lorelei, micah, avataaars, bottts, fun-emoji, notionists, adventurer, thumbs)
   - Personalización: 6 colores de acento, 8 avatares, nombre para mostrar

D. APP UNIFICADA (Nexo)
   - Ubicación: Proyecto predeterminado/unified-app/
   - URL: (pendiente de despliegue)
   - Funciones: auth (D1), dashboard, tareas (CRUD), grafo (iframe), GitHub, voz, chat, perfil
   - Base de datos: Cloudflare D1 (users + tasks)
   - API: /api/register, /api/login, /api/me, /api/preferences, /api/tasks

NOTAS
================================================================================

- La bóveda (Documentos/general/) solo contiene información/notas.

- Quartz usa symlink: content/ → bóveda.

- La base de datos D1 es SQLite en el edge (Cloudflare).
- Las contraseñas se hashean con SHA-256.
- El servidor local de la consola GitHub solo escucha en 127.0.0.1.
